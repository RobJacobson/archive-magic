# Archive Magic

Archive Magic is a planned toolset for downloading selected captures from public CDX-based web archives into portable WARC collections and replaying those collections locally.

## Status

Archive Magic is currently in its foundation stage and is not yet usable. Fetching and replay functionality have not been implemented.
