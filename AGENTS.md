# Contributor instructions

This repository contains Python tools. Its language and runtime conventions remain project-specific; the shared React/TypeScript coding and architecture defaults do not apply.

For Markdown, follow the [shared documentation style](https://github.com/RobJacobson/react-style-guide/blob/v0.1.0/documentation-style.md) and use the `technical-writing` skill for substantive prose. The root README opens with an introduction and operational setup; place the curated project-source directory tree in `FILES.md` through depth 3 (root = 0). The README's user-workspace and bucket trees describe separate runtime layouts.

When asked to commit, use a one-line Conventional Commit subject followed by a blank line and bullet points summarizing major changes.
